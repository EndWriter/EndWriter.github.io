Contexte

Développé durant mon stage au Pôle Formation UIMM, ce système de recommandation intelligent vise à orienter automatiquement les étudiants vers des certifications RNCP adaptées à leur profil, leurs compétences et leurs objectifs professionnels.

Pipeline ETL

  • Extract : Collecte de 5000 profils étudiants anonymisés (RGPD) depuis PostgreSQL + scraping de 8000+ certifications depuis France Travail
  • Transform : Nettoyage, encodage One-Hot, standardisation, feature engineering (score proximité géographique, score cohérence parcours)
  • Load : Structure en étoile PostgreSQL optimisée pour les requêtes analytiques

Modélisation

Comparaison de 3 algorithmes (KNN, Naive Bayes, Random Forest). Le Random Forest a été retenu avec 77% d'accuracy après optimisation et régularisation pour corriger le surapprentissage (gap réduit de 40pts à 4pts).

Résultats clés

  • Feature importance : Taux d'adéquation compétences (28%), Niveau d'études (22%), Score cohérence parcours (15%)
  • Réduction du surapprentissage via régularisation et réduction de la profondeur des arbres

Contexte

Le Pôle Formation UIMM gère 6500 étudiants/an, 70+ formations initiales et 700 formations continues. Avant AGILe, tout était géré via des fichiers Excel dispersés, créant des incohérences et une perte de temps considérable.

Architecture technique

  • Backend : Laravel 11.9 (PHP 8.2), Eloquent ORM, API REST avec 50+ endpoints
  • Frontend : Next.js 14 (React 18), Redux Toolkit pour la gestion d'état, Tailwind CSS
  • Base de données : PostgreSQL avec relations hiérarchiques (formations → modules → blocs → compétences)
  • Sécurité : Laravel Sanctum (authentification token-based), gestion des rôles
  • DevOps : Docker avec docker-compose, tests PHPUnit

Fonctionnalités développées

  • Gestion hiérarchique formations/modules/blocs/compétences avec navigation bidirectionnelle
  • Génération automatique de PDF avec DomPDF
  • Interface responsive (grille desktop, liste mobile)
  • Optimisation des requêtes avec eager loading pour éviter le problème N+1

Méthodologie

Projet géré en Agile Scrum avec sprints de 2 semaines, Daily Scrum quotidiens, Trello (Kanban) et GitLab (Git Flow avec merge requests obligatoires).

Contexte

Mise en situation professionnelle (MSP) réalisée dans le cadre de ma formation. Ce projet explore les fondamentaux du Machine Learning à travers l'implémentation et l'analyse d'un modèle de régression linéaire.

Objectifs pédagogiques

  • Comprendre les mécanismes de la régression linéaire simple et multiple
  • Maîtriser le processus complet : exploration, préparation, modélisation, évaluation
  • Interpréter les coefficients et les métriques de performance (R², MSE, MAE)
  • Visualiser les résultats et communiquer les insights

Contenu du notebook

  • EDA : Analyse exploratoire avec statistiques descriptives et visualisations
  • Preprocessing : Gestion des valeurs manquantes, normalisation, split train/test
  • Modélisation : Régression linéaire avec Scikit-learn
  • Évaluation : Métriques de performance et analyse des résidus
